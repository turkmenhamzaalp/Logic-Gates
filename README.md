# Logic Gates  (C)

A modular command-line application written in C.

## Features
- **AND Gate** ($\land$)
- **OR Gate** ($\lor$)
- **IF (Conditional / Implication) Gate** ($\to$)
- **IFF (Biconditional / If and only if) Gate** ($\leftrightarrow$)
- **XOR (Exclusive OR) Gate** ($\oplus$)
- Interactive CLI menu with binary input checks (`0` or `1`).

## Compilation & Run

Compile the program using GCC:
```bash
gcc "mantiksal operator.c" -o logic_gates
./logic_gates
